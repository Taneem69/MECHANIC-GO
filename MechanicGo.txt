# ROLE

Act as a Senior Software Architect, Product Manager, UI/UX Designer, Database Architect, Cybersecurity Expert, and Full-Stack Developer.

Your task is to design and develop a complete production-ready web platform called **MechanicGo** (name can be changed later).

The platform is inspired by Uber's service workflow but is specifically designed for on-demand vehicle repair and roadside assistance.

Do not give generic answers.

Provide complete professional software engineering documentation, system design, database design, UI design, user flow, security design, and implementation roadmap.

---

# PROJECT OVERVIEW

I want to build a platform where customers can request vehicle repair services wherever they are located.

Unlike Uber:

* There is NO pickup location.
* There is NO destination location.
* The mechanic always travels to the customer.
* Customer shares current location.
* Nearby mechanics receive the service request.
* Mechanic accepts the request and travels to the customer.
* Both parties can track each other in real time.

Initially build this as a WEBSITE.

Later it will be converted into Android and iOS applications.

Therefore the architecture should be designed in a scalable way so that mobile apps can be integrated later without major changes.
